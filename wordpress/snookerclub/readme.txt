Ranking, uitslagen, rapporten en invoer voor een snookerclub. Standaard klaar voor SC De Merodesnookers (Turnhout).

== Description ==

Clubnaam, locatie en kleuren pas je aan onder Snookerclub → Clubgegevens. Frames, winst en verlies volgen de WPBSA-regels. Seizoen loopt augustus–juli.

== Installation ==

1. Upload de zip (niet alleen de PHP-map).
2. Activeer de plugin.
3. Vul de clubnaam in.
4. Plaats shortcodes of het blok Snookerclub.

Zie docs/INSTALL.md in de bronmap.
